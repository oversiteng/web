# 05 — Architectural Gaps & Prioritized Remediation Plan

This document consolidates every verified architectural gap, missing piece, stub, and unverified path across the Oversite WebApp, followed by a dependency-ordered **P0 → P3 Remediation & Implementation Plan**.

---

## 1. Consolidated Architectural Gaps Register

### 1.1 Authentication, Session & RBAC Gaps
1. **Unverified JWT Signatures in Edge Proxy (`proxy.ts:38-64`)**: `getValidPayload()` decodes base64url JSON and checks `exp`/`sub` without verifying HMAC-SHA256. **Confirmed live**: forged unsigned JWT cookie (`role: "ADMIN"`) renders `/admin/dashboard` with `200 OK`.
2. **Missing SSR Route Protection (`proxy.ts:5-21, 185-209`)**: `/billing`, `/payments`, `/documents`, `/settings`, `/security`, `/support`, `/about`, and `/messages` are omitted from `PROTECTED_PREFIXES` and `matcher` (**confirmed live**: `200 OK` unauthenticated).
3. **Dead Session Revocation & Stale `isActive` (`lib/auth/sessionManager.ts:283-311`, `lib/auth/middleware.ts:40-88`, `app/api/v1/auth/logout/route.ts:4-22`)**: `validateSession()` has 0 callers; `logout` only clears cookie; `withAuth` never checks `users.isActive` or session revocation (**confirmed live**: Bearer token stays `200 OK` on `/auth/me` post-logout). `register/route.ts` also skips `createSession()`, and no refresh-token endpoint exists despite `signRefreshToken` (`lib/auth/jwt.ts:33-98`, which also hardcodes `role: "USER"`).
4. **AdminPolicy & `hasPermission` Unenforced (`lib/auth/adminPermissions.ts:120-199`, `lib/auth/rbac.ts:102`, `app/(admin)/layout.tsx:136-147`)**: `hasPermission()` has 0 callers; only `DELETE /api/v1/tasks/[id]` checks `extractAdminPolicy()`; `resolveModuleFromPath` omits `/admin/properties`. `setup-password/route.ts:56` skips `currentPassword` check when omitted.
5. **Hardcoded `"000000"` OTP / Reset Bypasses & Stub Auth UIs**:
   - `app/api/v1/auth/otp/verify/route.ts:19-24` and `app/api/v1/auth/reset-password/route.ts:45` unconditionally accept `"000000"`.
   - `app/(auth)/forgot-password/page.tsx:16-38`, `app/(auth)/reset-password/page.tsx:18-28`, and `app/(user)/security/page.tsx:215-247` (2FA enable) are disconnected stubs / skip OTP verification.
   - `POST /api/v1/agent/wallet/pin` (`pin/route.ts:51`) overwrites existing PIN if `currentPin` is omitted; `agent/wallet/page.tsx:143, 423, 455` stores PIN in plaintext in `localStorage`.
6. **API IDORs & Unauthenticated S3 Media Proxy**:
   - `GET /api/v1/media` (`app/api/v1/media/route.ts:21-63`) has **no `withAuth`** and serves private KYC IDs/bills with `Cache-Control: public`.
   - `GET/PATCH /api/v1/tasks/[id]`, `GET/POST/PATCH /api/v1/tasks/[id]/milestones`, `POST /api/v1/reports/submit`, `POST /api/v1/tasks/[id]/respond`, and `POST /api/v1/payments/{initialize,verify}` lack ownership/assignment checks; `GET /api/v1/agents`/`[id]` expose `ninId`/`nbaNumber` to `USER`.
   - Zero endpoints enforce `users.kycStatus === "VERIFIED"` (confirmed live: `PENDING` KYC agent claimed task).

### 1.2 Payment, Webhook, Wallet & Payout Integrity Gaps
1. **Unsigned Paystack Webhook Bypass (`app/api/v1/payments/webhook/route.ts:16-21`, `services/payment-service/src/index.ts:16-25`)**: Both handlers use `if (secret && signature)`, returning **`200 OK`** when `x-paystack-signature` is omitted (confirmed live on `:3000` and `:4000`).
2. **`OVS_` Auto-Verify Bypass & Arbitrary Client Amount (`app/api/v1/payments/verify/route.ts:83-86`, `initialize/route.ts:12-42`)**: `verify` marks any `OVS_*` reference `CAPTURED`; `initialize` accepts arbitrary client `amount` without checking `tasks.priceNgn` (confirmed live with `amount: 1000` on `₦15,000` task).
3. **6 of 7 Modules & Property Auto-Tasks Skip Payment**: `property-oversite`, `projects`, `diligence`, `legal`, `enforcement`, and `vulnerability` create `status: "PENDING"` directly without Paystack checkout, and UI catches errors to show success modals. `POST /api/v1/properties` inserts `quoteStatus: "PAID_ESCROW"` (`₦15,000`) with zero payment.
4. **Non-Idempotent Wallet Credits & Client `disburse` Abuse (`approve/route.ts`, `disburse/route.ts`, `payout/route.ts`, `admin/finance/overview/route.ts`)**: None check `payments.status === "RELEASED"` or `tasks.status === "COMPLETED"` inside a transaction; `disburse` lets clients pass `customAgentPayoutNgn`; `payout` defaults to 100% client `task.priceNgn`.
5. **Simulated Bank Withdrawals & Refunds (`agent/wallet/withdraw/route.ts:74-165`, `admin/finance/overview/route.ts:323-347`)**: `withdraw` executes no Paystack Transfer API (marks `COMPLETED` locally with `OVS-PAYOUT-*`) and runs non-atomically without `FOR UPDATE` / `WHERE balance >= amount` / `idempotencyKey` / `bankVerification` check. `REFUND_CLIENT` updates DB statuses only without calling Paystack `/refund`. Admin Finance Tab 2 (`admin/finance/page.tsx:266-353`) is read-only.
6. **Dead Payment Microservice & Missing Flutterwave**: `services/payment-service` (`:4000`) is unused by Next.js, lacks `PAYSTACK_SECRET_KEY` in Compose, and only logs webhooks. `FLUTTERWAVE` exists in enums only. `billing/add-card/page.tsx` is a `setTimeout` stub.

### 1.3 Schema Drift, Data Hygiene & Hardcoded Demo Data
1. **Schema Drift (`lib/db/migrate.ts:314` vs `db/schema.ts:464`)**: `runSafetyPatches()` defines `task_chats.moderation_status` as `varchar(30)`, whereas `db/schema.ts` defines it as `chat_moderation_status` pgEnum (safe on current DB only because `0000_lean_wendigo.sql` ran first).
2. **`properties.description` JSON Overloading & Broken FK Delete (`db/schema.ts:276-311`, `app/api/v1/properties/[id]/route.ts:244, 308-317`)**: `properties` lacks columns for `ownershipType`, `verificationStatus`, `baselinePhotos`, `proofOfOwnershipUrl`, and `intelTimeline`. `PATCH` overwrites `description` raw (destroying `__meta`), and `DELETE` hits `tasks.propertyId` FK without cascade/cleanup.
3. **Fabricated Demo Data Persisted/Rendered**: `getDefaultPropertyIntelTimeline()` (`lib/services/propertyTaskService.ts:28-153` — `"Tunde C."`, `"98%"`, Feb 2024 Lekki data), `DEFAULT_TASKS` (`dashboard/tasks/page.tsx`), `SAMPLE_STAGE_PHOTOS` (`dashboard/tasks/[id]/page.tsx`), `DEMO_PROPERTIES` (`vulnerability/page.tsx`), `urgent-today-due-diligence` (`agent/dashboard/page.tsx`), and fabricated `thisMonth`/`thisWeek` wallet stats (`agent/wallet/page.tsx:181-184`).
4. **Undeclared `sharp` Dependency & Repo Root Secrets**: `sharp` is absent from `package.json:20-53` (resolved only via `next`'s `optionalDependencies`). `oversite-key.pem` and `oversite-s3-app-user_accessKeys.csv` sit in repo root (gitignored, operational hygiene risk). `next.config.ts:31-32` & `proxy.ts:77-107` emit spec-invalid/overly permissive CORS (`Allow-Credentials: true` with `*` or reflected `Origin`).

### 1.4 Broken UI-to-API Contracts
- **Agent Queue `500` Crash**: `app/(agent)/agent/queue/page.tsx:55` sends `?status=PENDING,MATCHED`, crashing `app/api/v1/tasks/route.ts:52-54` with Postgres enum error (verified live).
- **Agent Signup Tier Coercion**: `register/agent/page.tsx:250-252` sends `"LEGAL"` / `"TECHNICAL"`, coerced to `"GENERAL"` by `register/route.ts:161`.
- **Double-Discounted Agent Pay**: `agent/tasks/page.tsx:206` (`0.7x`) and `agent/tasks/[id]/page.tsx:265` (`0.8x`) multiply an already 70% `agentPayoutNgn`.
- **Pricing Divergences**: 6 of 7 User UI modules display prices (`₦12k`–`₦26.1k`) that diverge from `lib/services/pricing.ts:88-96` (`₦15k`–`₦97.5k`).
- **Geofence & Report UI Bypass**: `agent/tasks/[id]/page.tsx:295-335, 563-590` ignores `400 GEOFENCE_VIOLATION` and `/reports/submit` HTTP errors; `/reports/submit` drops `severity`, `checklist`, `metadata`, `caption` and leaves `tasks.status` unchanged (while canonical `/tasks/[id]/reports` is unused).
- **Missing/Broken User Actions**: `POST /api/v1/tasks/[id]/rate` returns `404` (missing route); `dashboard/tasks/[id]/report/page.tsx` downloads a `.txt` Blob instead of `/api/v1/reports/[id]/pdf`; Property/Task/Admin list limits clamp silently (`limit=100`).
- **Admin KYC Split Path**: `admin/users/page.tsx:404-414` calls `/verify` which skips `addressVerificationStatus`, doc statuses, and `notifications`; `admin/tasks/[id]/page.tsx` skips `/api/v1/admin/tasks/[id]/milestones`; `admin/chat/page.tsx` skips `/api/v1/admin/chats/threads`.

### 1.5 Background Worker, Queue & Realtime Gaps
- **No Worker Container in Compose**: `docker-compose*.yml` lacks a worker service; 7 `SEND_EMAIL` jobs from `2026-11-16` plus 1 test `GENERATE_WATERMARK_PDF` job sat unconsumed in Redis `oversite:queue:jobs` (verified live).
- **Unimplemented Handlers**: `scripts/worker.ts` only processes `SEND_EMAIL` and drops other jobs; `worker.ts:19-27` has `// TODO` stubs for `AUTO_RELEASE_ESCROW` and `GENERATE_WATERMARK_PDF`.
- **Realtime Bridge & Admin Chat (`lib/realtime/websocketHandlers.ts:15-89`)**: No SSE route exists for `admin:chat:moderation`; `RedisSocketBridge` emits to both `localEmitter` and Redis (duplicating events) and shares a single `this.subscriber` client whose `unsubscribe` breaks all listeners on that channel.

### 1.6 PDF & Media Storage Gaps
- **Milestone PDFs `MISSING`**: No milestone PDF template or endpoint (`moderate/route.ts` with `generatePdf: true` sets React route `/dashboard/tasks/.../report` and overwrites the single `taskReports` row).
- **Phantom S3 Keys & Missing Media in PDF**: `compile/route.ts:60` stores a synthetic `pdfS3Key` without calling `pdfGenerator.ts` or `uploadFile()`; `generateWatermarkedReportPdf()` omits `reportMedia` photos/GPS and `incidentalExpenses`; `diligence/[id]/dossier` has no generation flow.
- **Base64 Fallback Bloat**: Property proof/photos (`properties/new/page.tsx`), User task attachments (`diligence`/`legal`/`enforcement` never upload files), and Agent S3 fallback (`lib/storage/agentUpload.ts:240-249`) store raw base64 or filenames without S3 persistence. `AdminLayout` DLP modal (`layout.tsx:810-816`) breaks on non-image evidence (PDF/video).

### 1.7 Unimplemented Subscription & External API Architecture
- **Subscriptions & Credits (`docs/SUBSCRIPTION_PLANS_AND_FEATURES.md`)**: Zero DB tables exist for plans, subscriptions, credit ledgers, or recurring schedules (`GET /api/v1/subscriptions` and `POST /upgrade` are static/notification-only mocks; `creditBalance` is ad-hoc JSONB inside `accreditationDocuments`).
- **External Partner API (`lib/api/externalAuth.ts:20`)**: Calls `request.headers.get("")`, causing **live HTTP `500`** on all `/api/v1/external/*` endpoints (`/health`, `/notifications`, etc.).

# 02 — User / Client Flow Audit (R1)

**Core Summary:** All three User/Client flows — **Account Creation**, **Property Registering**, and **Task Placing** — have working happy-path UI and API scaffolding, but exhibit severe architectural breaks between UI and backend contracts:
1. **Account Creation** skips email/OTP verification, omits `userSessions` creation, uses disconnected `STUB` UIs for Forgot/Reset Password and 2FA activation, and leaves `validateSession()` uncalled (`logout` does not invalidate Bearer JWTs).
2. **Property Registering** stores raw base64 images/documents inside `properties.description` instead of S3, auto-dispenses a `PAID_ESCROW` task with zero payment and hardcoded fictional intelligence data, and lacks Edit/Delete UI (with a broken FK-constrained `DELETE` API).
3. **Task Placing & Lifecycle** bypasses Paystack checkout on 6 of 7 modules, mismatches UI vs. backend pricing, drops uploaded files, leaves `tasks/[id]` & `milestones` open to IDOR, and uses `STUB` / `MISSING` endpoints for report PDF download, card saving, and agent rating.

2. **Property Oversight (`User -> Admin -> Agent -> User`)**: Property registration auto-creates `PROPERTY_OVERSITE` (`PAID_ESCROW`); Admin can dispense subscription tasks (`POST /api/v1/admin/properties/[id]/dispense`) and publish timeline intel (`POST /api/v1/admin/properties/[id]/intel`) into `properties.description.__meta.intelTimeline` + `taskChats`.
3. **Hub-and-Spoke Chat (`User <-> Admin <-> Agent`)**: Unlocks when `tasks.agentId` is set OR `moduleType === "PROPERTY_OVERSITE"` (`chat/[taskId]/messages/route.ts:72, 231`). Messages enter `PENDING_REVIEW` and remain hidden until Admin moderates. (Live SSE `/api/v1/chat/[taskId]/stream` **`UNVERIFIED`**.)
4. **Deliverable & Escrow Settlement (`Agent -> Admin -> User -> AgentWallet`)**: Agent submits milestones/report -> Admin compiles -> User approves (`/tasks/[id]/approve` -> `COMPLETED`/`RELEASED`, wallet credit) or disputes (`/tasks/[id]/dispute` -> `DISPUTED`).
